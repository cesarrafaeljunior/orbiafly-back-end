# Visao do produto

Orbiafly e uma aplicacao de organizacao financeira pessoal. Seu objetivo e centralizar informacoes financeiras de forma simples, clara e confiavel, reduzindo o esforco necessario para entender a situacao financeira do usuario.

O produto comeca para uso individual, mas os dados e os limites de dominio deverao considerar uma evolucao futura para multiplos usuarios.

O primeiro fluxo implementado substitui o controle manual de despesas recorrentes mensais. O usuario configura uma despesa fixa uma vez e acompanha valor, vencimento, categoria e pagamento em cada competencia sem reset mensal.

## Principios de produto

- Informacoes compreensiveis antes de excesso de detalhes.
- Precisao e previsibilidade em operacoes financeiras.
- Privacidade e seguranca desde a entrada de dados.
- Evolucao incremental, orientada por necessidades reais.
